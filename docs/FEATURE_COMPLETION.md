# Windows 本地 Git 功能完成与自测记录

日期：2026-10-07。分支：`feat_SC_git-client-tools`。发行版本：**1.1.0**。

范围依据上一轮 Git Graph / Git History / GitLens / Fork 对照表，仅补齐 Windows 本地缺口。PR/Issue 协作、云补丁及其他平台按要求排除。没有必须等待用户决定才能完成的事项。用户已授权推送并发布 1.1.0；发布不会替换本机已安装的版本。

## 已完成

| 能力 | 入口及行为 |
| --- | --- |
| 整仓比较 | 完整提交图 → 仓库工具 → 比较版本；输入任意分支、标签、提交或相对引用，可选从共同祖先比较。提交/引用右键可设置比较起点与终点。 |
| 文件审阅状态 | 提交详情或比较结果的文件左侧复选框，按仓库和版本组合在本机保存；扩展通过主机持久化。 |
| 远程管理 | 仓库工具 → 管理远程；添加、删除、重命名，分别修改 Fetch / Push URL。 |
| 交互式变基 | 仓库工具 → 交互式变基；选择保留基点，调整后续提交顺序及 pick/reword/edit/squash/fixup/drop，可输入重写说明。 |
| Reflog 恢复 | 仓库工具 → Reflog 恢复；每页 200 条，从选中提交创建新分支，不覆盖当前分支或工作文件。 |
| 图片差异 | 完整界面显示前后图；扩展原生版本文件系统返回原始图片字节。支持 PNG/JPEG/GIF/WebP/BMP/ICO。 |
| 克隆/初始化 | 点击顶部“+”进入欢迎页；克隆选择父目录、地址和新文件夹名，初始化选择现有目录。拒绝覆盖已有仓库及非空克隆目标。 |
| 历史分页 | 扩展文件历史、行历史和搜索每页 200 条，显示“加载更多”；前后版本导航可跨页。重命名历史跨页保留旧路径。 |
| 本地改动后的行历史 | 对当前编辑器内容与 HEAD 做映射；插入/删除导致的行号偏移不再错位，未保存内容也参与映射。 |
| 大文件读取 | 大补丁每页 1000 行只读预览；原生历史文本大小通过 `pushright.history.maxFileSizeMiB` 调整。 |

以上仓库工具由桌面版和扩展的“打开提交图”完整界面共用；侧栏的紧凑提交图维持原有交互。扩展自带引擎，无须安装桌面程序。系统 Git for Windows 仍然必需。

## 数据保护与明确边界

- 变基开始前校验 HEAD 未变化、工作区干净、提交集合完整、动作有效；创建 `pushright-backup/<时间戳>` 分支。发生冲突沿用现有“继续/中止”。提交说明写入数据文件，不能作为 shell 指令执行。
- 变基编辑器处理当前 HEAD 祖先之后的线性区间；不处理根提交或含合并提交的区间，会明确报错，不会静默展开合并历史。`edit` 暂停后可在工作区修补提交再继续。
- 行历史仅映射未改变的选区；选区含新增或被修改的行时明确提示，可改查文件历史或提交后再查。它不会改写工作文件或索引。
- 原生历史文本默认 4 MiB，设置范围 4–64 MiB；图片上限为每侧 32 MiB。其他二进制仍走整文件操作。
- 超过 4 MiB 或 5000 行的补丁可以切换只读分页；分页不提供部分暂存/丢弃，整文件操作保留。单行超过 64 KiB 截断并提示。
- 补丁后续页重新扫描 Git 输出；文件历史为保持 `--follow` 重命名正确性，会读取已加载前缀再切页。未宣称大型仓库性能提升；原性能报告的数据不代表新增分页的基准。
- 不承诺与四款工具全部功能等价。自动获取、应用自动更新、合并拓扑编辑，以及不在本次对照表中的专用功能未新增。

## 自测

所有写操作测试在临时或项目示例仓库进行，没有重写用户工作仓库的历史，也没有连接真实远程进行推送。

原生界面检查属于入口和显示验收；克隆、初始化、恢复分支和实际重写等写流程由真实 Git 集成测试验证，未逐一通过鼠标重复执行。编辑器测试日志含宿主的 mutex/退出清理诊断，Cursor 独立测试配置另有未登录诊断；测试断言全部通过，进程退出码均为 0。
